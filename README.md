SALLE DE SPORT-API REST SPRING BOOT

DESCRIPTION
Ce projet consiste à développer une API REST pour la gestion d'une salle de sport.
L'application permet de gérer principalement deux entités liées :Adherent et Abonnement
Le projet utilise une architecture en couches afin de séparer les différentes responsabilités de l'application.

TECHNOLOGIES UTILISEES
Java 17
Spring Boot
Spring Data JPA
MySQL
POSTMAN

FONCTIONNALITES
Gestion des adhérents
Gestion des abonnements
CRUD complet
Relation Adhérent / Abonnement
Validation des données
Gestion des erreurs
Pagination et tri
Swagger / OpenAPI
Lancer le projet
Créer la base de données salle_sport dans MySQL.
Vérifier la configuration dans application.properties.
Lancer SalleSportApplication.java.

L'application fonctionne sur :

http://localhost:8080

SWAGGER:
http://localhost:8080/swagger-ui.html

ENDPOINTS:
/api/adherents
/api/abonnements
